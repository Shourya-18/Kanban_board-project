# Kanban Board

A simple **Kanban Board** built using **HTML, CSS, and JavaScript**. It allows users to create tasks, organize them into different stages, and move tasks between columns using drag and drop.

## 🔗 Live Demo

[Kanban Board](http://127.0.0.1:5593/html/KanbanBoard.html)

## ✨ Features

- Add new tasks
- Add task title and description
- Three task stages:
  - To Do
  - In Progress
  - Done
- Drag and drop tasks between columns
- Delete tasks
- Automatic task count for each column
- Tasks are saved using Local Storage
- Data remains available after refreshing the page
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Drag and Drop API
